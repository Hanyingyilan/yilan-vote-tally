# 宜蘭市開票統計

宜蘭市 **82 個投開票所**、**5 種選舉**的開票回報網站：
- **投開票所人員用手機點開就能回報**各候選人的票數；
- **你在電腦上打開同一個網址**，就能看到每位候選人目前累計多少票（每 20 秒自動更新）；
- 依「**市民代表選舉區 → 里 → 投開票所**」分類。

純靜態網站（HTML / CSS / JS，沒有建置步驟、沒有套件），放 GitHub Pages 即可。
要「大家的票數合在一起」需要再接 Google 試算表（見下方，約 10 分鐘）。

| 宜蘭市里長（38 個里） | 69 人 | **依里各一份名單**（其中 18 個里只有 1 位候選人） |

## 怎麼用

**回報（手機）**：打開網址 →「填寫票數」→ 上方選一種選舉 → 點投開票所 → 輸入各候選人得票與無效票 → 按「儲存」。
- 一個投開票所的表單裡可以用頂端分頁切換不同選舉，只會儲存你有改動的那幾項。
- 填完按「**完成並送出**」。**這支手機第一次送出時，會直接跳出視窗請你輸入密碼**（密碼由負責人提供），輸入後就會送出，之後這支手機會記住，不會再問。密碼打錯會提示「密碼不對，請再輸入一次」。
- 送出後畫面**留在原處**，不會自己跳到別的投開票所，並用大字顯示結果：
  - ✅ 綠色「已送出！票數已傳到雲端」＝成功；
  - ⏳ 金色「傳送中…請稍等」；
  - ⚠ 紅色「還沒送出！」＝沒送出去（沒密碼、網路不通或密碼錯），旁邊有大按鈕「輸入同步密碼」；票數還在手機裡，不用重填，有網路時會自動補傳。
- 要離開時按「回到清單」。
- 每項選舉各自有「未開票／開票中／已完成」狀態；有填票但沒選狀態時，會自動記成「開票中」。

**填合計（給拿得到合計數字的人）**：在「填寫票數」頁最上面切到「**合計**」，可以直接填
- 全市合計（市長、縣長、縣議員）、
- 各市民代表選舉區合計（市長、縣長、縣議員、市民代表）、
- 各里合計（五種選舉都可以，里長只有這一層）。

合計和各投開票所的票**分開存放，不會被重複加總**。在投開票所現場回報的人不用填合計。

**查看（電腦）**：打開同一個網址 →「統計總覽」→ 選一種選舉，看
- **最上面就是各候選人累計得票與得票率**（依票數排序；有席次的選舉，前 N 名會亮色，席次邊界同票會標「同票」）；
- 其次是完成進度、有效票、無效票；
- 市長／縣長／縣議員另有「各市民代表選舉區」「各里」表格；市民代表按 4 個選舉區各一張榜；里長按 38 個里各一張榜；
- 「手動合計對照」：把填的合計和各投開票所加總並排，不一致的用紅字標「差」；
- 全部投開票所明細；匯出 CSV／JSON；列印或存成 PDF。

CSV 是「長表」（一列＝一個範圍×一種選舉×一位候選人），最右邊的「類型」欄區分「投開票所」和「合計」，可直接丟進 Excel／Google 試算表做樞紐分析。

離線也能填：資料先存在手機瀏覽器，有網路時自動補傳。

## 防呆：填錯、手滑、亂填

**填表當下**（按「完成並送出」時，不合理會先問一次，按「取消」就回去修改，什麼都不會存）：
- **數字太大**：一個投開票所的「投票數合計」超過 **1,200 票**，會跳出「數字很大！有沒有多打了一個數字？」。合計填寫的門檻會隨範圍放大（例如某個里有 3 個投開票所，就是 3,600）。
- **和同一所的其他選舉差太多**：這一項選舉選「已完成」時，若和同一個投開票所另一項「已完成」的選舉票數差超過 35%（且票數 100 以上），也會先問。

- **送出前再確認是哪一所**：按「完成並送出」後，一定會先跳出「請確認是不是這一所：0015 ○○國小、○○里、共 N 票」，防止填到隔壁所。按「取消」就回去看看。
- **「初始化雲端表格」有保護**：雲端已有票數時，必須打字輸入「我要清空」才會執行，避免開票夜誤按。**只有正式開票前（或演練完）才該按。**

**統計頁**（站在你這邊看）：
- 選舉按鈕上會出現 **⚠數字**（例如「市長 20/82 ⚠4」）。
- 每項選舉最下面有「**⚠ 需要確認的投開票所**」清單，列出原因、填表人與時間，旁邊有「去修改」按鈕，點了直接跳到那一所的表單。
- 「全部投開票所明細」表會標紅可疑的所，並顯示**填表人與時間**。
- 判斷的條件：投票數超過 1,200、比其他所多很多（超過中間值 2.2 倍）、比其他所少很多（已完成但不到中間值 35%）、無效票超過 15%、和同一所其他選舉差很多。

**1,200 這個門檻怎麼來的**：用中選會「選舉資料庫」2014–2024 年共 12 場選舉（縣長、市長、總統、立委）的宜蘭市各里得票，除以 2026 年名單中該里的投開票所數，推算每所的有效票：平均約 570–700 票，單一投開票所最多 963 票（2024 總統，該里只有 1 所，數字是實際值）；地方選舉最多約 890 票。門檻取歷年最多的 1.25 倍，約 1,200。這是估算，不是官方的每所選舉人數；如果要改，編輯 `app.js` 開頭的 `LIMIT_STATION`。

**後台歸零（在 Google 試算表上操作）**：貼上最新的 `Code.gs` 並重新部署後，重新整理試算表，上方選單列會多一個「**開票工具**」：
- **全部歸零（清空所有票數）**：顯示目前有幾筆票數，要輸入「我要清空」才會執行。適合演練完、正式開票前使用。
- **歸零某一個投開票所**：輸入編號（例如 `0015`；合計輸入 `ALL`、`D1`～`D4`、`V:七結里`），再選哪一項選舉（留空＝這一所全部），確認後歸零。
- 歸零會把票數清掉、狀態改回「未開票」，並蓋上現在的時間，所以**所有人的手機約 20 秒內也會跟著變成未開票**，不會把舊資料傳回來。
- 第一次使用 Google 會要求授權，按「允許」即可（若出現「Google 尚未驗證這個應用程式」，點「進階 → 前往…」）。

**發現填錯了怎麼改**：到「填寫票數」找到那一所，重新填正確的數字再按「完成並送出」，新的會蓋掉舊的。也可以在試算表「檔案 → 版本記錄」退回之前的版本。懷疑有人亂填，立刻到 Apps Script 改 `TOKEN`（見下方「串接 Google 試算表」），舊密碼馬上失效。

## 部署到 GitHub Pages

```bash
cd yilan-vote-tally
git init && git add . && git commit -m "宜蘭市開票統計"
git branch -M main
git remote add origin git@github.com:<你的帳號>/<repo 名稱>.git
git push -u origin main
```

**之後每次更新網站**（改了程式或名單）：先執行 `python3 tools/bump_version.py`，再 commit、push。這會更新 `index.html` 裡的版本號；手機上已經打開的網站會在**沒有開著表單、沒有未送出票數**時自動重新整理成新版，不用請大家手動更新。

接著到 GitHub repo → **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
幾分鐘後網址是 `https://<你的帳號>.github.io/<repo 名稱>/`。

> GitHub Pages 是公開網站。**不要把同步密碼寫進 `config.js`**。

## 串接 Google 試算表（讓大家的票數合在一起）

不串接也能用，但每個人的資料只在自己的手機裡，你的電腦看不到。串接後所有人回報的票會集中到同一份試算表，總覽頁自動合併。

1. 建一份新的 Google 試算表。
2. **擴充功能 → Apps Script**，把 [`apps-script/Code.gs`](apps-script/Code.gs) 全部貼上取代預設內容。
3. Apps Script 左側 **專案設定 → 指令碼屬性 → 新增**：名稱 `TOKEN`，值是你自訂的同步密碼（只給填表人）。
4. **部署 → 新增部署作業 → 類型選「網頁應用程式」**：執行身分「我」；誰可以存取「**任何人**」。第一次會要求授權。
5. 複製網址（結尾 `/exec`）。可以寫進 [`config.js`](config.js) 的 `syncUrl`（這樣所有人打開網站就自動連線），或各人到 ⚙ 設定貼上。
6. 打開網站右上角 **⚙ 設定**：貼上網址、輸入同步密碼、輸入你的名字 → **儲存設定** → **初始化雲端表格**。
   會建立兩個分頁：
   - 「得票明細」：全部投開票所×選舉×候選人的長表（2,984 列，含各選舉的「無效票」列），票數即時寫入這裡；手動填的合計會在第一次儲存時另外附加成「類型＝合計」的列；
   - 「彙總」：用公式算出每位候選人的「各所加總」（不含合計列）、得票率、完成所數，以及「手動合計」，兩欄並排方便對照。
7. 回報人員各自在手機設定同樣的網址與密碼（只看總覽的人只要網址，不用密碼）。

同步規則：
- 以「投開票所×選舉」為單位，**最後更新時間較新的蓋掉舊的**；不同人同時回報不同選舉不會互相覆蓋。
- 讀取不需密碼（開票結果本來就公開），寫入一定要密碼。網址和密碼都外洩的話任何人都能改票數；開票結束後可到 Apps Script 刪除部署。
- 「得票明細」分頁請不要改表頭，也不要刪掉最右邊兩個隱藏欄（`updatedAtMs`、`key`）。要在試算表直接修正票數，請把該列 `updatedAtMs` 改成比目前大的數字（例如把原本的數字加 1），否則網站端會以較新的時間為準、下次同步又蓋回去。

## 更新資料

**候選人**（開票前務必再核對一次）：

```bash
B=https://info.cec.gov.tw/vote2026/static/json
D=tools/source/candidates
curl -s -o $D/cand_C1_10002.json            $B/cand/C1/10002.json
curl -s -o $D/cand_T_10002.json             $B/cand/T/10002.json
curl -s -o $D/cand_D1_10002.json            $B/cand/D1/10002.json
curl -s -o $D/cand_R_10002.json             $B/cand/R/10002.json
curl -s -o $D/cand_V1_10002_10002010.json   $B/cand/V1/10002/10002010.json
python3 tools/build_candidates.py
```

**投開票所**：把新的官方 ODS 放到 `tools/source/stations_115.ods`，執行 `python3 tools/build_stations.py`。

兩個腳本都只用 Python 標準函式庫；會自動檢查里、選舉區、候選人是否對得上。**重新產生後請 commit 並 push**。
開票開始後，不要再改候選人號次，否則已填的票數會對錯人。

## 已知限制

- 這是登錄與暫計工具，**不是官方開票結果**。
- 候選人名單是 2026-11-09 取自中選會網站的版本。
- 縣長、縣議員的票數在宜蘭市內分投開票所登錄，本站只加總宜蘭市範圍，**不含其他鄉鎮**，所以看不到全縣結果。
- 縣議員只涵蓋宜蘭市所屬的第 1 選舉區；平地／山地原住民縣議員不在這個網站內。
- Apps Script 後端沒有在真實 Google 環境跑過：開發時用模擬的試算表環境驗證了寫入、覆蓋、較舊更新被忽略、重新初始化不洗掉資料等邏輯，並用假伺服器驗證前端同步，但**第一次部署請先用假資料「測試連線」和「初始化雲端表格」確認**，再正式使用。
- 網站沒有帳號系統；同步密碼是簡單的共用密碼。
