# 宜蘭市開票統計

宜蘭市 **82 個投開票所**、**5 種選舉**的開票回報網站：
- **投開票所人員用手機點開就能回報**各候選人的票數；
- **你在電腦上打開同一個網址**，就能看到每位候選人目前累計多少票（每 20 秒自動更新）；
- 依「**市民代表選舉區 → 里 → 投開票所**」分類。

純靜態網站（HTML / CSS / JS，沒有建置步驟、沒有套件），放 GitHub Pages 即可。
要「大家的票數合在一起」需要再接 Google 試算表（見下方，約 10 分鐘）。

## 多個鄉鎮市（county 分支）

這個分支把網站改成可以開多個鄉鎮市，目前有**宜蘭市**和**礁溪鄉**。

- **切換**：頁首標題的鄉鎮市名稱就是選單；也可以直接用網址 `…/?town=礁溪鄉`（傳給礁溪鄉回報員的連結用這個）。沒帶參數時，會開這支手機上次看的鄉鎮市，第一次則是宜蘭市。
- **用詞會跟著換**：礁溪鄉顯示鄉長、鄉民代表、村長、全鄉；宜蘭市顯示市長、市民代表、里長、全市。
- **資料各存各的**：每個鄉鎮市在 Google 試算表有自己的分頁（宜蘭市＝「得票明細」「彙總」「回報員」「修改記錄」；礁溪鄉＝「礁溪鄉 得票明細」「礁溪鄉 彙總」「礁溪鄉 回報員」「礁溪鄉 修改記錄」）；手機上的暫存、記住的密碼也分開。
- **管理員密碼**：預設所有鄉鎮市共用 `TOKEN`。想讓礁溪鄉有自己的管理員密碼（例如交給礁溪鄉的負責人），在 Apps Script 的指令碼屬性加一個 `TOKEN_礁溪鄉`；加了之後，`TOKEN` 就不能寫礁溪鄉，`TOKEN_礁溪鄉` 也不能寫宜蘭市。
- **每人一組密碼（回報員名單）**：每個鄉鎮市各一份名單。**先點到礁溪鄉的任何一個分頁**（例如「礁溪鄉 得票明細」），再按 **開票工具 → 回報員名單**，做出來的就是「礁溪鄉 回報員」；產生的專屬連結會帶 `?town=礁溪鄉`，點開直接進礁溪鄉。礁溪鄉名單上的密碼只能回報礁溪鄉，動不到宜蘭市的資料，反過來也一樣。一個人兩邊都要回報，就兩邊名單各寫一列、各拿一個連結。
- **修改記錄**：礁溪鄉有人蓋掉數字，記在「礁溪鄉 修改記錄」；宜蘭市的記在「修改記錄」。
- **試算表可以分開**：想讓某個鄉鎮市用另一份 Google 試算表（另一個 Apps Script 後端），在 [`config.js`](config.js) 的 `syncUrls` 寫上那個鄉鎮市的網址，例如 `syncUrls: { "礁溪鄉": "https://script.google.com/macros/s/…/exec" }`。沒寫的鄉鎮市用 `syncUrl`。分開之後兩份試算表各有自己的 `Code.gs`、自己的 `TOKEN`、自己的名單，互不相干：**宜蘭市那份貼 `main` 分支的 `Code.gs`，礁溪鄉那份貼 `county` 分支的 `Code.gs`**。
- **預覽版**：`python3 tools/make_preview.py <資料夾>` 會做出只有礁溪鄉的一份網站（最上面有一條「預覽版」、不連正式的試算表），放在正式網站底下的 `/preview/` 給負責人先試。
- **第一次開一個鄉鎮市**：貼上最新的 `Code.gs` 並重新部署 → 網站切到那個鄉鎮市 → ⚙ →「初始化雲端表格」，會自動建立它的兩個分頁。
- **歸零**：先點到那個鄉鎮市的分頁，再按「開票工具」。只會清那個鄉鎮市。
- **保護**：後端還沒更新成支援鄉鎮市的版本時，宜蘭市以外的鄉鎮市一律不會送出票數（會顯示「雲端後端還沒更新」），避免把別的鄉鎮市的票寫進宜蘭市的表。
- **要再開一個鄉鎮市**：看 `tools/build_towns.py` 開頭的說明（12 個鄉鎮市的代表選舉區應選名額都已記在檔案裡）。
- **還沒做**：把各鄉鎮市的縣長、縣議員票數加總成「全縣」的頁面。

礁溪鄉資料（官方來源同宜蘭市）：36 個投開票所（0216–0251）、18 村、30 個地點；鄉長 4 人；鄉民代表 4 個選舉區應選 5／1／2／3 席（共 11 席）；村長 35 人；屬縣議員第 3 選舉區（應選 3 席，5 人）。

## 怎麼用

**回報（手機）**：打開網址 →「填寫票數」→ 上方選一種選舉 → 點投開票所 → 輸入各候選人得票與無效票 → 按「儲存」。
- 一個投開票所的表單裡可以用頂端分頁切換不同選舉，只會儲存你有改動的那幾項。
- 填完按「**完成並送出**」。**這支手機第一次送出時，會直接跳出視窗請你輸入密碼**（密碼由負責人提供），輸入後就會送出，之後這支手機會記住，不會再問。密碼打錯會提示「密碼不對，請再輸入一次」。
- 送出後畫面**留在原處**，不會自己跳到別的投開票所，並用大字顯示結果：
  - ✅ 綠色「已送出！票數已傳到雲端」＝成功；
  - ⏳ 金色「傳送中…請稍等」；
  - ⚠ 紅色「還沒送出！」＝沒送出去（沒密碼、網路不通或密碼錯），旁邊有大按鈕「輸入同步密碼」；票數還在手機裡，不用重填，有網路時會自動補傳。
- 要離開時按「回到清單」。
- 每項選舉各自有「未開票／開票中／已完成」狀態；有填票但沒選狀態時，會自動記成「開票中」。

**填合計（給拿得到合計數字的人）**：在「填寫票數」頁最上面切到「**合計**」，可以直接填
- 全市合計（市長、縣長、縣議員）、
- 各市民代表選舉區合計（市長、縣長、縣議員、市民代表）、
- 各里合計（五種選舉都可以，里長只有這一層）。

合計和各投開票所的票**分開存放，不會被重複加總**。在投開票所現場回報的人不用填合計。

**查看（電腦）**：打開同一個網址 →「統計總覽」→ 選一種選舉，看
- **最上面就是各候選人累計得票與得票率**（依票數排序；有席次的選舉，前 N 名會亮色，席次邊界同票會標「同票」）；
- 其次是完成進度、有效票、無效票；
- 市長／縣長／縣議員另有「各市民代表選舉區」「各里」表格；市民代表按 4 個選舉區各一張榜；里長按 38 個里各一張榜；
- 「手動合計對照」：把填的合計和各投開票所加總並排，不一致的用紅字標「差」；
- 全部投開票所明細；匯出 CSV／JSON；列印或存成 PDF。

CSV 是「長表」（一列＝一個範圍×一種選舉×一位候選人），最右邊的「類型」欄區分「投開票所」和「合計」，可直接丟進 Excel／Google 試算表做樞紐分析。

離線也能填：資料先存在手機瀏覽器，有網路時自動補傳。

## 防呆：填錯、手滑、亂填

**填表當下**：按「完成並送出」後，只會跳出**一個**大字的確認視窗「是這一所嗎？」，上面寫投開票所編號、名稱、里，以及這次要送出的各項票數，並直接問「**票開完了嗎？**」：
- 綠色「**開完了，送出**」→ 這一項標成「已完成」。
- 橘色「**還在開，先送出目前的**」→ 標成「開票中」，之後可以再更新。
- 「回去修改」→ 什麼都不會存。
- 表單上不用再自己選狀態。數字沒變、只是要從「開票中」改成「已完成」，打開那一所直接按「完成並送出」再選「開完了」即可。
- 把某一項的格子**全部清空**再送出，那一項會變回「未開票」（填到隔壁所時用）。

有下面任何一種情況，會在同一個視窗用紅框提醒：
- **數字太大**：一個投開票所的投票數合計超過 **1,200 票**（合計填寫的門檻會隨範圍放大，例如某個里有 3 個投開票所就是 3,600）。
- **和同一所的其他選舉差太多**：兩項都「已完成」卻差超過 35%（且票數 100 以上）。
- **別人填過這一所**：這一項已經有另一位填表人送出的票數，或你填寫期間被別人改過，會寫出「○○ 在 19:02 填過，送出後會蓋掉原本的數字」。表單上方也會顯示「上次填寫：○○ 19:02」。
- **還有空格**：選了「已完成」但有格子沒填（會當成 0）。

**第一次送出要填名字**：這支手機還沒填過名字時，確認視窗裡會多一格「你的名字（只要填這一次）」，沒填不能送出；填過就記住，之後不再問。名字會記在試算表的「填表人」欄，也用來顯示「上次填寫：○○」和「○○ 填過」的提醒。

確認視窗是網站自己畫的（不是瀏覽器內建的小視窗），字大、按鈕大，在 LINE 內建瀏覽器裡也能正常使用。

- **「初始化雲端表格」有保護**：雲端已有票數時，必須打字輸入「我要清空」才會執行，避免開票夜誤按。**只有正式開票前（或演練完）才該按。**

**統計頁**（站在你這邊看）：
- 選舉按鈕上會出現 **⚠數字**（例如「市長 20/82 ⚠4」）。
- 每項選舉最下面有「**⚠ 需要確認的投開票所**」清單，列出原因、填表人與時間，旁邊有「去修改」按鈕，點了直接跳到那一所的表單。
- 「全部投開票所明細」表會標紅可疑的所，並顯示**填表人與時間**。
- 判斷的條件：投票數超過 1,200、比其他所多很多（超過中間值 2.2 倍）、比其他所少很多（已完成但不到中間值 35%）、無效票超過 15%、和同一所其他選舉差很多。

**1,200 這個門檻怎麼來的**：用中選會「選舉資料庫」2014–2024 年共 12 場選舉（縣長、市長、總統、立委）的宜蘭市各里得票，除以 2026 年名單中該里的投開票所數，推算每所的有效票：平均約 570–700 票，單一投開票所最多 963 票（2024 總統，該里只有 1 所，數字是實際值）；地方選舉最多約 890 票。門檻取歷年最多的 1.25 倍，約 1,200。這是估算，不是官方的每所選舉人數；如果要改，編輯 `app.js` 開頭的 `LIMIT_STATION`。

**後台歸零（在 Google 試算表上操作）**：貼上最新的 `Code.gs` 並重新部署後，重新整理試算表，上方選單列會多一個「**開票工具**」：
- **全部歸零（清空所有票數）**：顯示目前有幾筆票數，要輸入「我要清空」才會執行。適合演練完、正式開票前使用。
- **歸零某一個投開票所**：輸入編號（例如 `0015`；合計輸入 `ALL`、`D1`～`D4`、`V:七結里`），再選哪一項選舉（留空＝這一所全部），確認後歸零。
- 歸零會把票數清掉、狀態改回「未開票」，並蓋上現在的時間，所以**所有人的手機約 20 秒內也會跟著變成未開票**，不會把舊資料傳回來。
- 第一次使用 Google 會要求授權，按「允許」即可（若出現「Google 尚未驗證這個應用程式」，點「進階 → 前往…」）。

**發現填錯了怎麼改**：到「填寫票數」找到那一所，重新填正確的數字再按「完成並送出」，新的會蓋掉舊的（時間最新的那一筆為準，所有人的畫面約 20 秒內一致）。整所清掉重填，用試算表「開票工具 → 歸零某一個投開票所」。**不要用試算表的「版本記錄」退回來修單筆錯誤**：退回後雲端的時間變舊，已經看過錯誤數字的手機和電腦會繼續顯示錯的，兩邊不一致；版本記錄只當「不小心全部歸零」時的最後救援，救完後每台要看統計的裝置都要在 ⚙ 按「清除這台裝置上的所有資料」再重新整理。懷疑有人亂填：用每人一組密碼時，到「回報員」分頁把那個人打勾停用，再照「修改記錄」把數字改回來；用共用密碼時，立刻到 Apps Script 改 `TOKEN`（見下方「串接 Google 試算表」），舊密碼馬上失效。

## 部署到 GitHub Pages

```bash
cd yilan-vote-tally
git init && git add . && git commit -m "宜蘭市開票統計"
git branch -M main
git remote add origin git@github.com:<你的帳號>/<repo 名稱>.git
git push -u origin main
```

**之後每次更新網站**（改了程式或名單）：先執行 `python3 tools/bump_version.py`，再 commit、push。這會更新 `index.html` 裡的版本號；手機上已經打開的網站會在**沒有開著表單、沒有未送出票數**時自動重新整理成新版，不用請大家手動更新。

接著到 GitHub repo → **Settings → Pages** → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)`。
幾分鐘後網址是 `https://<你的帳號>.github.io/<repo 名稱>/`。

> GitHub Pages 是公開網站。**不要把同步密碼寫進 `config.js`**。

## 串接 Google 試算表（讓大家的票數合在一起）

不串接也能用，但每個人的資料只在自己的手機裡，你的電腦看不到。串接後所有人回報的票會集中到同一份試算表，總覽頁自動合併。

1. 建一份新的 Google 試算表。
2. **擴充功能 → Apps Script**，把 [`apps-script/Code.gs`](apps-script/Code.gs) 全部貼上取代預設內容。
3. Apps Script 左側 **專案設定 → 指令碼屬性 → 新增**：名稱 `TOKEN`，值是你自訂的同步密碼（人少時直接發給填表人共用；人多時見下方「每人一組密碼」）。
4. **部署 → 新增部署作業 → 類型選「網頁應用程式」**：執行身分「我」；誰可以存取「**任何人**」。第一次會要求授權。
5. 複製網址（結尾 `/exec`）。可以寫進 [`config.js`](config.js) 的 `syncUrl`（這樣所有人打開網站就自動連線），或各人到 ⚙ 設定貼上。
6. 打開網站右上角 **⚙ 設定**：貼上網址、輸入同步密碼、輸入你的名字 → **儲存設定** → **初始化雲端表格**。
   會建立兩個分頁：
   - 「得票明細」：全部投開票所×選舉×候選人的長表（2,984 列，含各選舉的「無效票」列），票數即時寫入這裡；手動填的合計會在第一次儲存時另外附加成「類型＝合計」的列；
   - 「彙總」：用公式算出每位候選人的「各所加總」（不含合計列）、得票率、完成所數，以及「手動合計」，兩欄並排方便對照。
7. 回報人員各自在手機設定同樣的網址與密碼（只看總覽的人只要網址，不用密碼）。

同步規則：
- 以「投開票所×選舉」為單位，**最後更新時間較新的蓋掉舊的**；不同人同時回報不同選舉不會互相覆蓋。
- 讀取不需密碼（開票結果本來就公開），寫入一定要密碼。網址和密碼都外洩的話任何人都能改票數；開票結束後可到 Apps Script 刪除部署。
- 「得票明細」分頁請不要改表頭，也不要刪掉最右邊兩個隱藏欄（`updatedAtMs`、`key`）。要在試算表直接修正票數，請把該列 `updatedAtMs` 改成比目前大的數字（例如把原本的數字加 1），否則網站端會以較新的時間為準、下次同步又蓋回去。

## 每人一組密碼（回報員名單）與修改記錄

回報員人數多（例如超過 30 人）時，共用一組密碼只要有一個人外流，就得全部重發。可以改成每個人一組：

1. 試算表上方 **開票工具 → 回報員名單：產生每個人的密碼和連結**。第一次按會建立「回報員」分頁。（這是宜蘭市的名單；別的鄉鎮市請先點到那個鄉鎮市的分頁再按，會建立「礁溪鄉 回報員」這樣的分頁，見最上面「多個鄉鎮市」。）
2. 在「名字」欄一列填一位回報員，填完再按一次同一個選單，每個人就會有自己的密碼和「專屬連結」（密碼是自動產生的 6 碼數字；想自己訂也可以直接打在「密碼」欄，至少 6 個字、每人不同）。
3. 把專屬連結**私訊**給本人（不要貼在群組）。他點一下就登入，不用打密碼，也不用再填名字；之後這支手機會記住。
4. 要停掉某個人：在「停用」那一欄打勾，立刻生效，其他人不受影響。取消打勾就恢復。

細節：
- 指令碼屬性的 `TOKEN` 變成**管理員密碼**，一樣什麼都能填，只有它能「初始化雲端表格」。改成每人一組之後，請把 `TOKEN` 換成只有你知道的新密碼，原本發出去的共用密碼就失效了。
- 用個人密碼送出的票，「填表人」一律記名單上的名字，手機上打別的名字也沒用，所以每一筆是誰送的查得到。
- 連結裡的密碼在網站打開後會馬上從網址列消失；同一個連結可以在同一個人的多支手機上用。
- 沒有「回報員」分頁（或名單是空的）時，就只有 `TOKEN` 一組密碼，和以前一樣。
- 新增的人、清空密碼的人，再按一次選單就會補上；已經有的密碼不會被換掉。
- 專屬連結開頭預設是正式網站的網址。要換成別的網址（例如測試用的預覽網址），在指令碼屬性加 `SITE_URL`，再按一次選單，連結就會換掉（密碼不變）；測完把 `SITE_URL` 刪掉再按一次就換回來。

**修改記錄**：有人蓋掉原本填過的數字時（不論是誰、用哪一組密碼），「修改記錄」分頁會多一列，寫著誰送的、哪一所、哪一項、**改之前**和**改之後**的數字。被亂改時，照「改之前」那一欄，用管理員密碼到網站把那一所重新填回去就好。第一次填、歸零後第一次填、數字沒變的重送都不會記。

## 填表人名字不公開

- 名字只記在 Google 試算表的「填表人」欄，以及**輸入過同步密碼的裝置**上（表單的「上次填寫：○○」、統計頁明細的「填表人／時間」）。
- 沒有密碼的人（一般民眾）打開網站，只看得到更新時間，看不到名字；直接讀資料網址也拿不到名字。
- 這需要最新版的 `Code.gs`。後端還是舊版時，網站畫面一樣不會顯示名字，但資料網址裡仍然有。

## 上次回報的

回報過的手機，下次打開「填寫票數」時，最上面會出現「上次回報的」那一所，一點就進去，不用再從 82 所裡找。同一個地點有好幾所時，在搜尋框打地點名稱（例如「宜蘭大學」）就會列出那個地點全部的投開票所。

## 手機相容性與多人同時觀看

- **舊 iPhone（iOS 15.3 以前）**沒有網站原本用的視窗功能，會自動改用一般浮層，功能相同。想在新手機或電腦上看這個模式，網址後面加 `?nodialog=1`。
- **更舊的瀏覽器**（大約 2020 年以前、沒再更新的）完全無法執行時，畫面會顯示「這支手機的瀏覽器太舊」並請對方改用 Chrome／Safari 或換手機，不會只看到一片空白。
- 版面沒有使用舊 Android 不支援的排版語法；最窄 320px 的手機不會左右捲動。
- **很多人同時看統計頁**：後端把讀取結果快取 15 秒，大家讀的是同一份；有人送出票數或後台歸零時，快取會立刻清掉。所以別人送出的票數，最慢約 20–35 秒會出現在其他人的畫面上。每台裝置的更新時間也錯開了幾秒。

## 已知限制

- 這是登錄與暫計工具，**不是官方開票結果**。
- 候選人名單是 2026-11-09 取自中選會網站的版本。
- 縣長、縣議員的票數在宜蘭市內分投開票所登錄，本站只加總宜蘭市範圍，**不含其他鄉鎮**，所以看不到全縣結果。
- 縣議員只涵蓋宜蘭市所屬的第 1 選舉區；平地／山地原住民縣議員不在這個網站內。
- Apps Script 後端沒有在真實 Google 環境跑過：開發時用模擬的試算表環境驗證了寫入、覆蓋、較舊更新被忽略、重新初始化不洗掉資料等邏輯，並用假伺服器驗證前端同步，但**第一次部署請先用假資料「測試連線」和「初始化雲端表格」確認**，再正式使用。
- 網站沒有帳號系統；預設是一組共用密碼，人多時可改用上面的「每人一組密碼」。
- 每人一組密碼只限制「誰能送」和「哪個鄉鎮市」，沒有限制「能填哪幾所」：同一個鄉鎮市裡，任何一位回報員都能填任何一所（方便臨時代班），亂填靠「修改記錄」查出來並改回去。
- 多個鄉鎮市的名單、專屬連結、修改記錄，同樣只在模擬的試算表環境和本機假伺服器測過（含 375px 手機寬度實際操作礁溪鄉），**還沒有在真的 Google 試算表和真手機上跑過**；第一次開礁溪鄉時，請先用一筆假資料走一遍再正式發連結。
